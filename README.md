# SO-language-trends-2020-2024
This project analyzes programming language popularity and developer preference
using data from the Stack Overflow Developer Surveys (2020–2024).

## Data Source
Stack Overflow Developer Survey 2020-2024 (public datasets)

## Methods
- Descriptive statistics
- Trend analysis
- Visualization using Python

## Tools
- Python
- pandas
- matplotlib
- Jupyter Notebook
